## Prompting Best Practices

### 1. Context Setting
- Clearly define the current phase of development
- Specify any existing constraints or requirements
- Reference relevant documentation or code
- Indicate the desired output format

### 2. Iterative Refinement
- Start with high-level prompts
- Gradually add more specific details
- Build upon previous responses
- Request alternatives when needed

### 3. Quality Assurance
- Request explanations for decisions
- Ask for pros and cons of approaches
- Validate against requirements
- Cross-reference with best practices

### 4. Documentation Generation
- Request structured formats
- Include examples and use cases
- Maintain consistency across documents
- Link related documentation
