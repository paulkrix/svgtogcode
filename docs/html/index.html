SVG to GCode Converter Documentation

Welcome to the official documentation for the SVG to GCode Converter, a specialized software tool designed to transform vector graphics (SVG files) into machine-readable GCode instructions for CNC machines, with special support for grayscale-to-depth mapping.

Latest Version: v1.0.0 - This documentation covers all features available in the current release.

About This Project

The SVG to GCode Converter is an open-source tool for hobbyist CNC users with GRBL controllers. It allows you to convert standard SVG vector files into optimized GCode, with the unique ability to interpret grayscale color values as depth (Z-axis) information.
